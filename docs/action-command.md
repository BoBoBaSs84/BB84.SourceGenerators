# ActionCommand Generator

Generates `ICommand` properties for methods marked with `[ActionCommand]`. The command kind is inferred from the method signature, and the command runtime types (`IActionCommand`, `IAsyncActionCommand`, ...) are emitted into your project, so no runtime package is required. Together with the [Notification Properties Generator](notification-properties.md) this completes the MVVM tool set.

[← Back to overview](../README.md) · [All generators](README.md)

## Why

MVVM view models expose `ICommand` properties for every user action. Writing a command class, a backing field and the `CanExecute` wiring for each method is repetitive, and async commands add concurrency and cancellation concerns. This generator creates the command properties from your methods, infers sync/async and parameter types from the signature, and ships the command runtime types as source, so no extra package is needed.

## Benefits

- Generates `ICommand` properties at compile time with lazily created backing fields
- Infers sync, async, parameterized and cancellable commands from the method signature
- Ships the command runtime types as source - no runtime package dependency
- Async commands prevent concurrent executions by default and support cancellation via `CancelCommand`
- Integrates with the Notification Properties Generator through `[NotifyCanExecuteChanged]`
- Compile-time diagnostics for invalid signatures, `CanExecute` members and name conflicts

## Attributes

```csharp
[ActionCommand(Name = null, CanExecute = null, ExceptionHandler = null, AllowConcurrentExecutions = false, IncludeCancelCommand = false)]
[NotifyCanExecuteChanged(params string[] commandNames)]
```

**Options:**

- `Name` - The name of the generated command property. By default, the method name without an `Async` suffix followed by `Command` (`Save` and `SaveAsync` both become `SaveCommand`)
- `CanExecute` - The name of a `bool` property, field or parameterless method that guards the command. For commands with a parameter, a `bool M(T)` method is also accepted. Properties generated by `[GenerateNotifications]` from `bool` fields can be referenced as well
- `ExceptionHandler` - _(async only)_ The name of a `void M(Exception)` method that receives exceptions thrown by the command. When not set, exceptions are rethrown
- `AllowConcurrentExecutions` - _(async only)_ When `true`, the command can be executed again while a previous execution is still running. By default, `CanExecute` returns `false` while the command is executing
- `IncludeCancelCommand` - _(async only)_ When `true`, an additional `{Name}CancelCommand` property is generated (e.g. `SearchCancelCommand`) that forwards to the command's `CancelCommand`

**Field-Level Attributes:**

- `[NotifyCanExecuteChanged(...)]` - Used with `[GenerateNotifications]`. Calls `RaiseCanExecuteChanged()` on the named commands whenever the decorated field or partial property changes.

## Usage

### Example

```csharp
using BB84.SourceGenerators.Attributes;

[GenerateNotifications]
public partial class SearchViewModel
{
    [NotifyCanExecuteChanged(nameof(SearchCommand), nameof(ClearCommand))]
    private string _query = string.Empty;

    private bool CanSearch => !string.IsNullOrWhiteSpace(Query);

    [ActionCommand(CanExecute = nameof(CanSearch))]
    private void Clear() => Query = string.Empty;

    [ActionCommand(CanExecute = nameof(CanSearch), ExceptionHandler = nameof(OnError), IncludeCancelCommand = true)]
    private async Task SearchAsync(CancellationToken cancellationToken)
        => await _service.SearchAsync(Query, cancellationToken);

    [ActionCommand]
    private void Open(ResultItem item) { /* ... */ }

    private void OnError(Exception exception) { /* log */ }
}
```

### Generated Code

```csharp
public partial class SearchViewModel
{
    private global::BB84.SourceGenerators.Commands.IAsyncActionCommand? _searchCommand;

    /// <summary>
    /// Gets the command that invokes <c>SearchAsync</c>.
    /// </summary>
    public global::BB84.SourceGenerators.Commands.IAsyncActionCommand SearchCommand
        => _searchCommand ??= new global::BB84.SourceGenerators.Commands.AsyncActionCommand(cancellationToken => SearchAsync(cancellationToken), canExecute: () => CanSearch, onException: exception => OnError(exception));

    /// <summary>
    /// Gets the command that cancels the running execution of <see cref="SearchCommand"/>.
    /// </summary>
    public global::BB84.SourceGenerators.Commands.IActionCommand SearchCancelCommand
        => SearchCommand.CancelCommand;
}
```

The `Query` setter generated by the Notification Properties Generator additionally calls `SearchCommand.RaiseCanExecuteChanged()` and `ClearCommand.RaiseCanExecuteChanged()`.

### Usage Example

```xml
<TextBox Text="{Binding Query, UpdateSourceTrigger=PropertyChanged}" />
<Button Content="Search" Command="{Binding SearchCommand}" />
<Button Content="Cancel" Command="{Binding SearchCancelCommand}" />
```

```csharp
SearchViewModel viewModel = new();
viewModel.Query = "hello";

await viewModel.SearchCommand.ExecuteAsync();
viewModel.OpenCommand.Execute(selectedItem);
```

### Supported Signatures

| Method signature                                           | Generated property type  |
| ---------------------------------------------------------- | ------------------------ |
| `void M()`                                                 | `IActionCommand`         |
| `void M(T parameter)`                                      | `IActionCommand<T>`      |
| `Task M()`                                                 | `IAsyncActionCommand`    |
| `Task M(CancellationToken cancellationToken)`              | `IAsyncActionCommand`    |
| `Task M(T parameter)`                                      | `IAsyncActionCommand<T>` |
| `Task M(T parameter, CancellationToken cancellationToken)` | `IAsyncActionCommand<T>` |

Static methods generate static command properties; their `CanExecute` and `ExceptionHandler` members must be static as well.

### Emitted Runtime Types

The following public types are emitted into the `BB84.SourceGenerators.Commands` namespace of every project that references the package:

- `IActionCommand` / `IActionCommand<T>` - `CanExecute()`, `Execute()`, `RaiseCanExecuteChanged()`
- `IAsyncActionCommand` / `IAsyncActionCommand<T>` - `ExecuteAsync()`, `ExecuteAsync(CancellationToken)`, `CanExecute()`, `Cancel()`, `RaiseCanExecuteChanged()`, `IsExecuting`, `IsCancellationRequested`, `CancelCommand`
- `ActionCommand` / `ActionCommand<T>` and `AsyncActionCommand` / `AsyncActionCommand<T>` - The implementations, which can also be instantiated manually

Behavior notes:

- Every async execution gets a token that is linked to `Cancel()` / `CancelCommand` and to the optional external token passed to `ExecuteAsync`. An `OperationCanceledException` caused by that token completes the command without an error.
- `ICommand.CanExecute(object)` / `ICommand.Execute(object)` of generic commands never throw for an incompatible parameter: `null` is accepted only when `T` accepts `null`, other mismatches are rejected.
- Because the runtime types are public, two referenced assemblies that both use the generator will each contain their own copy (`CS0436` warning).

## Diagnostics

| ID           | Severity | Description                                                                                                                           |
| ------------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `BB84SG0018` | Error    | The containing type of an `[ActionCommand]` method is not a `partial` class or record class                                           |
| `BB84SG0019` | Error    | The method signature is not supported (see _Supported Signatures_; `ref`/`out`/`in` parameters and generic methods are not supported) |
| `BB84SG0020` | Error    | The `CanExecute` member was not found or is not a compatible `bool` property, field or method                                         |
| `BB84SG0021` | Error    | The `ExceptionHandler` method was not found or is not `void M(Exception)`                                                             |
| `BB84SG0022` | Warning  | `ExceptionHandler`, `AllowConcurrentExecutions` or `IncludeCancelCommand` was set on a synchronous command and is ignored             |
| `BB84SG0023` | Error    | The generated command property or backing field collides with an existing member or another generated command                         |
| `BB84SG0024` | Warning  | `[NotifyCanExecuteChanged]` references a name that is neither an existing member nor a generated command                              |
